Parts made in 2010, correct until 2050

Everything under FocusOn's hood is a choice this boring, this old, and this hard to break.

Git

CSV

Readable with cat in 2050. No database, no company, no API required.

03 · DELIVERY

PDF

Clients get a PDF. That's the whole invoice — no portal, no login link.

04 · AUTOMATION

CLI

Script it, cron it, pipe it. Every action a plain command, nothing hidden behind a UI.

Widget

A native floating window. Survives full-screen apps, remembers where you left it.

No spinners, no outages

Boring technology has no backend to go down — no spinner, no outage, no "service temporarily unavailable" the moment a client is waiting on an invoice. The widget and the CLI read your own files. There is no server to have an incident.
